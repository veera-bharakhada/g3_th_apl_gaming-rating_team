# Data

## Dataset used in M2

The M2 experiments use synthetically generated match data. No external dataset download is required to run the main synthetic experiments.

The synthetic data represents player skill changes over time and binary outcomes between two players. Because the underlying simulated skill trajectories are known, the project can calculate skill-recovery metrics.

## Data preparation

The synthetic data is generated by the project scripts during the experiment workflow. To reproduce the experiments, run the source scripts or execute the `M2_Group3_Colab_Demo.ipynb` notebook in the order described in the main project `README.md`.

## Real-world data

Historical ATP match data is not used for the reported synthetic KPIs. Processing and evaluating real match data is a potential future extension and would require documenting the source, date range, preprocessing, and train/validation/test split.

## Reproducibility

Record the random seed and experiment configuration when generating data. The main benchmark uses seeds 42–51.
