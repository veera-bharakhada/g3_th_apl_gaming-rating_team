Implementation of the TrueSkill Through Time (TTT) Bayesian network model and baselines.

## Contents (to be added)
- `representation/` — Bayesian network / factor graph construction
- `learning/` — parameter learning (skill dynamics variance, priors) from data
- `inference/` — the three inference methods:
  - exact inference (two-team matches)
  - approximate inference (multi-team matches)
  - win/lose/draw outcome handling
- `baselines/` — Elo and original (forward-only) TrueSkill implementations
- `utils/` — shared helper functions (data loading, evaluation metrics)
