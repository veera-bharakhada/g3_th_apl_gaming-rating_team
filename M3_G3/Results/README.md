# Results – M3 Experimental Evaluation

## Overview

This folder contains the experimental outputs generated by the M3 implementation notebook.

The files document the model comparison, statistical evaluation, robustness experiments and player-level error analysis.

## Files

| File | Description |
|---|---|
| `main_10_seed_results.csv` | Individual experimental results for ten random seeds. |
| `main_summary_mean_sd.csv` | Mean and standard deviation of the main evaluation metrics. |
| `sample_size_robustness.csv` | Results for different numbers of matches per time point. |
| `missing_observation_robustness.csv` | Results under different missing-observation rates. |
| `observation_noise_robustness.csv` | Results under different observation-noise levels. |
| `player_error_analysis_seed42.csv` | Player-level MAE comparison for seed 42. |
| `paired_mae_test.json` | Paired statistical test and bootstrap confidence interval for MAE improvement. |

## Evaluation Metrics

The experiments use the following metrics:

- **MAE:** Mean Absolute Error for player-skill estimation.
- **RMSE:** Root Mean Squared Error for player-skill estimation.
- **Log-loss:** Evaluation of predicted match probabilities.
- **Brier Score:** Evaluation of probabilistic prediction accuracy.
- **Runtime:** Computational time required by each model.

## Experimental Configuration

The main experiments use ten fixed random seeds (42–51). Robustness experiments examine sample size, missing individual observations and observation noise.

## Reproducibility

These files are generated by executing the M3 Jupyter Notebook. The notebook contains the corresponding experimental procedures and calculations.

The results are based on synthetic data and should be interpreted within the limitations described in the M3 report.
