# Bayesian Network-Based Estimation and Comparison of Player Skill Over Time

**CSE 516 — Probabilistic Graphical Models | M1 | Group 3**

This project studies **TrueSkill Through Time (TTT)** for estimating time-varying player skill using Bayesian inference.

### Focus
- Representation: Dynamic Bayesian Network / Factor Graph
- Inference: Exact Sum-Product, Loopy BP, and EP
- Learning: Parameter learning using evidence/predictive likelihood
- Baselines: Elo, TrueSkill, and Constant Skill
- Dataset: Historical ATP tennis matches
- SOTA Reference: BONG (NeurIPS 2024)
